These baseline runbooks define safe operator gates and recovery order. They become executable only after M0 supplies environment-specific identifiers, commands, expected outputs, evidence locations, roles, timeouts, and abort thresholds. Until then they are review-ready procedures, not authorization to operate on live systems.
